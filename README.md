# 🧪 Projeto de Testes Automatizados de API com Cypress

Este projeto contém testes automatizados de **API REST** utilizando o **Cypress**, com foco em validações de endpoints, contratos e respostas HTTP.  
O objetivo é garantir a qualidade e a integridade das APIs por meio de testes automatizados rápidos e consistentes.

---

## 🚀 Requisitos

Antes de rodar o projeto, é necessário ter instalado em sua máquina:

- [Node.js](https://nodejs.org/en/) (versão 18 ou superior)
- [npm](https://www.npmjs.com/) (instalado junto com o Node)
- [Cypress](https://www.cypress.io/) (instalado no projeto)
- Editor de código (recomendado: [VS Code](https://code.visualstudio.com/))

---

## 📦 Instalação do Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/usuario/projeto-cypress-api.git

2. Acesse a pasta do projeto:
cd teste_api

3. Instale as dependências
npm install

4.Executar projeto
npx cypress open ou npx cypress run
